HOW TO INSTALL THIS
-------------------
Clone the repo first, then from inside the repo folder run ONE command:

  tar -xf "%USERPROFILE%\Downloads\nammamart_all_bhavani.zip" --strip-components=1

That drops everything into the right folders and overwrites README.md.

Then copy the dataset (only include/ is mounted into Docker):

  mkdir include\data\nammamart 2>nul & copy assignment\nammamart_dataset\* include\data\nammamart\

Then verify:

  pip install pandas
  python include/profiling/profile_nammamart.py --data include/data/nammamart --out include/profiling/out

Expected: 34 issue groups, 550 offending rows
